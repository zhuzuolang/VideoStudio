# 影序 FrameFlow

面向短剧团队的 AI 制片工作台。第一版以《雾港来信》为示例项目，打通故事设计、人物设定、剧本、生产拆解、视觉资产、分镜预演与成片交付的产品流程。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可。发布前可运行：

```bash
npm test
```

## 当前范围

- 一套可切换的完整制作阶段导航
- 贯穿各模块的统一示例项目数据
- AI 创作搭档、连续性检查与建议采用反馈
- 桌面、平板与移动端响应式布局
- Cloudflare Sites 兼容构建

当前数据和 AI 响应为前端演示状态；后续可接入项目数据库、模型路由、生成任务队列与团队身份系统。
